# Course Website

## Overview
This is a responsive educational website developed using HTML and CSS. The website is designed to showcase courses, learning programs, and educational resources through a clean and user-friendly interface.

## Features
- Responsive Design
- Modern User Interface
- Course Information Sections
- Easy Navigation
- Mobile-Friendly Layout
- Clean and Structured Design

## Technologies Used
- HTML5
- CSS3

## Project Structure
├── index.html
├── style.css
└── images/

## Purpose
The purpose of this project is to demonstrate frontend web development skills by creating an attractive and responsive educational website.
